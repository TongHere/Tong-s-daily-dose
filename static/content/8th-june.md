**Productivity Gains with the Feel-Good/Fun Effect**

I read a book today, and it's about how feeling fun at work is likely to increase productivity. 

I really like this concept — gamify the working experience, and don't think of the task as a challenge. Instead, think about it as: if I were a character in a game, how would I win this scenario? In this way, it can help a lot to reduce stress and increase the 'fun' during work. 

Quite often, I gave myself stress when doing tasks, thinking about what could go wrong and how to solve it. I gave myself a lot of unnecessary stress. But now, I think of it as a kind of game — how to behave, act, and take action to make sure I crack the game and win the prize. It helps me a lot to make challenging work more joyful and enjoyable!
